# 拾光创作园 · Sidequest Workbench

**把多账号创作的任务、选题与实验，放进一个安静有序的个人工作台。**

面向个人创作者的中文 Web 应用，帮助你回答三个问题：今天做什么、目前卡在哪里、下一步是什么。采用墨绿与纸白的编辑风界面，桌面三栏布局，同时适配窄屏操作。

使用 React、TypeScript 与 Vite 构建。无需后端、登录或 API 密钥，首次打开即可体验演示数据。

## 能做什么

| 工作区 | 功能 |
| --- | --- |
| 今日 | 确认今日计划、查看创作节奏、搜索与筛选任务、推进下一步 |
| 任务 | 创建、编辑、删除任务；管理账号、主题、优先级与计划时间 |
| 内容主题 | 整理选题，查看关联任务数量，新增与重命名主题 |
| 实验 | 记录假设、观察指标与结论，跟踪实验进度 |
| 历史 | 按日期查看完成记录，按账号、结果和关键词筛选 |
| 设置 | 管理账号、个人资料、每日与每周目标、紧凑模式，以及数据备份 |

任务按照「待撰稿 → 待拍摄 → 剪辑中 → 待发布 → 已完成」推进，也可以通过编辑调整回之前的状态。这里的发布操作用于记录状态，不会向内容平台实际发布内容。

界面支持键盘焦点、弹窗焦点约束、Escape 关闭与减少动态效果偏好。

## 快速开始

准备 Node.js `20.19+`（20.x）或 `22.12+` 与 npm。

```bash
git clone https://github.com/LJC-god/sidequest-workbench-public.git
cd sidequest-workbench-public
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:5173`。

第一次使用建议：

1. 在「设置」中修改个人资料，添加自己的内容账号。
2. 在「内容主题」中整理选题分类。
3. 创建一个任务，设置账号、主题与计划日期。
4. 回到「今日」推进任务，完成后在「历史」中查看记录。
5. 定期在「设置」中导出 JSON 备份。

## 本地数据与备份

数据保存在当前浏览器、当前站点的 `localStorage` 中，存储键为 `sidequest-workbench:v1`，数据版本为 `schemaVersion: 1`。首次访问会生成演示数据，之后的修改会自动保存并在刷新后恢复。

- **导出 JSON**：下载完整数据，用于备份或手动迁移。
- **导入 JSON**：校验数据结构、实体引用、日期与版本，确认后替换当前数据。建议先导出备份。
- **重置为演示数据**：确认后覆盖当前数据。
- **损坏数据恢复**：发现无效数据或不支持的版本时，应用会保留原始存储内容，并提供下载原始数据与重置入口。

浏览器清理站点数据可能导致数据丢失；不同浏览器、设备、域名或端口之间不会自动同步。浏览器存储容量有限，本项目适合个人轻量管理，不提供登录、团队协作或云同步。

## 构建与部署

```bash
npm run build
npm run preview
```

`build` 会先运行 TypeScript 检查，再生成 `dist/`。`preview` 用于本地检查生产构建，默认地址为 `http://localhost:4173`。

可以将 `dist/` 发布到支持静态文件的托管服务：

| 配置 | 值 |
| --- | --- |
| 安装命令 | `npm ci` |
| 构建命令 | `npm run build` |
| 输出目录 | `dist` |

默认配置适用于站点根路径。如果部署到 `/sidequest-workbench-public/` 这样的子路径，请在 `vite.config.ts` 中设置对应的 `base` 后重新构建：

```ts
export default defineConfig({
  base: '/sidequest-workbench-public/',
  plugins: [react()],
});
```

切换站点地址前，请从旧地址导出数据，再在新地址导入。

## 项目结构

```text
public/                  站点图标等静态资源
src/
  components/            工作区视图、任务表单与通用弹窗
  App.tsx                应用入口与页面组织
  useWorkbench.ts        状态管理与用户操作
  storage.ts             本地持久化、导入校验与异常恢复
  seed.ts                首次使用的演示数据
  types.ts               数据类型与状态定义
  date.ts                本地日历日期处理
  styles.css             布局、主题与响应式样式
index.html               HTML 入口
vite.config.ts           构建配置
```

技术栈：React · TypeScript · Vite · Lucide React。

## 开发检查

提交修改前运行 `npm run build`，并在浏览器中检查相关操作。涉及数据管理时，至少确认任务创建与状态推进、刷新后的数据恢复，以及 JSON 导入导出流程。

当前没有独立的自动化测试脚本。欢迎通过 Issues 提交问题，请附上复现步骤、浏览器信息与预期行为；不要附上包含私人内容的完整数据备份。
